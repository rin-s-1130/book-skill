# book-skill

ページ写真から、全文テキストと意味構造を分離した「Reading Atlas」を生成し、線形な文章を読む際の認知負荷を下げるためのCodex Skillプロジェクトです。

現在は要件定義段階です。実装と技術設計はまだ開始していません。
